# dotfiles

Personal config for [Omarchy](https://omarchy.org) (Arch + Hyprland) setups.
Only files that diverge from the Omarchy defaults in
`~/.local/share/omarchy/config/` are tracked here.

Two machines share this repo: shared config lives at the root, and anything
machine-specific (monitors, keyboard layout, bindings, waybar) lives under
`hosts/<machine>/` as an overlay applied on top of the shared base.

## Layout

| Path in repo | Installs to |
|---|---|
| `home/.*` | `~/` |
| `bin/` | `~/.local/bin/` |
| `claude/` | `~/.claude/` (see `claude/README.md`) |
| `icons/default/` | `~/.icons/default/` |
| `hosts/<machine>/` | `~/.config/<same path>` (overlay, after base) |
| everything else | `~/.config/<same path>` |

## Hosts

- **laptop** — Acer, eDP-1 2880x1800 + HDMI-A-1 1080p, PT layout, iGPU
  (`waybar/scripts/gpu.sh`), F-row quirk bindings, VRR, zero borders.
- **desktop** — DP-4 4K @ 1.5 + HDMI-A-2 1080p rotated 90°, US layout with
  RAlt compose, nvidia (`nvidia-smi` waybar module), 1px border, volume keys
  on Super+Alt+PgUp/PgDn, session restore at boot (see below).

## Install

```sh
git clone https://github.com/Chaingenhash/dotfiles ~/dotfiles
cd ~/dotfiles
HOST=laptop   # or: desktop

for f in home/.*; do [ -f "$f" ] && cp "$f" ~/; done
cp -r icons/default ~/.icons/
mkdir -p ~/.local/bin && cp bin/* ~/.local/bin/
rsync -a --exclude README.md --exclude .git --exclude .gitignore \
      --exclude home --exclude icons --exclude claude --exclude bin \
      --exclude hosts ./ ~/.config/
rsync -a hosts/$HOST/ ~/.config/
cp -r claude/settings*.json claude/themes ~/.claude/
```

On the **desktop**, `hypr/autostart.conf` sources `~/.config/hypr/session.conf`,
which is generated and not tracked — create it before the first reload:

```sh
touch ~/.config/hypr/session.conf   # or run hypr-session-save once
```

## Session restore (desktop)

`bin/hypr-session-save` snapshots the current windows (class, workspace,
monitor) into `session.conf`/`session-layout.tsv`; launch commands per window
class live in `hosts/desktop/hypr/session-apps.conf`. At boot, `session.conf`
relaunches everything and `bin/hypr-session-restore` corrects placement once
the windows have spawned. Nothing is pinned afterwards. Requires `jq`.

## What's customized

- **hypr** — per-host monitors/layout/bindings (see Hosts above); shared:
  opaque focused windows, Bibata-Modern-Ice cursor via `envs.conf`,
  fullscreen keeps waybar, Super+L locks.
- **waybar** — per-host: mpris module, kanji workspace icons, cpu/memory/GPU
  readouts (`gpu.sh` on the iGPU laptop, `nvidia-smi` on the desktop).
- **fonts** — Iosevka Nerd Font instead of JetBrainsMono, across ghostty,
  kitty, hyprlock, swayosd, fontconfig (desktop kitty stays JetBrainsMono).
- **terminals** — ghostty default (`xdg-terminals.list`), OSC52 toast off;
  alacritty carries an explicit Tokyo Night palette.
- **shell** — `home/.zshrc` mirrors Omarchy's bash setup in zsh (fzf-tab,
  starship, mise, zoxide, a zsh-safe `tsl`, `lg`/`ldk` aliases; `ls` → eza
  comes from the sourced Omarchy aliases).
- **claude code** — plugin set, hooks, theme; see `claude/README.md`.
- **opencode** — plugin pins (gemini-auth, superpowers).
- **misc** — btop layout, lazygit nerd fonts v3, mise toolchain pins,
  wiremix device naming, chromium theme extension.

## Not tracked

- `~/.config/git/config` — machine-local identity and credential helpers.
- `~/.XCompose` — only customization is a compose shortcut that expands to a
  personal email address.
- `~/.config/hypr/session.conf` / `session-layout.tsv` — generated by
  `hypr-session-save`.

Deliberately kept out of a public repo.
